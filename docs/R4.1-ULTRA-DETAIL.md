# NEOWULF v6 R4.1 Ultra Detail

R4.1 is the correction pass after visual QA of R4.

The important change is that the runtime now visibly differs from the previous build rather than only adding hidden assets. The three oscillator decks are real Winamp `Vis` components and all three are visible on first load. Deck 1 is a wide stereo fire-trace oscilloscope, Deck 2 is independent left/right, and Deck 3 is a mirrored twin trace.

The Left/Right VU component is digital, not an analog-needle face. It uses black glass with bright white scale detail and a 120-frame red/white-hot segmented response. The animation layer stays inside the display aperture. The legacy framed power lamp was removed from this component.

Generic LEDs are no longer 30x30 black squares with round colored bulbs. The same compatibility atlas coordinates are preserved, but the actual drawn emitter is now a thin transparent micro-slot. The component power indicator is likewise a flush horizontal red slot.

The speaker windows remain 298x1044 (roughly three times the earlier cabinet height). The right tower and every right driver frame are generated as exact horizontal mirrors of the left assets.

The physically-correct R3 turntable model is retained: the record material rotates, while the platter, strobe reference and stylus/deck lighting remain fixed.

## Resolution model

Winamp Modern skin XML uses fixed logical pixel coordinates. Supplying a 4K-sized runtime bitmap for a 638x246 component would break geometry. R4.1 therefore renders source artwork at 8x resolution (638x246 becomes 5104x1968 during rendering), then downsamples with Lanczos into 32-bit RGBA runtime PNGs. This gives high-detail edges and gradients without changing the Winamp layout contract.
